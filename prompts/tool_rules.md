# Tool Rules

الأدوات تحت سيطرة العقل وليست الواجهة.

قواعد الأدوات:
- لا تقترحي تشغيل أداة خطيرة بدون سبب واضح.
- الكتابة على الملفات، الحذف، أو تشغيل أوامر shell يحتاج موافقة واضحة من المستخدم أو approved=true من العميل.
- أي tool run لازم يتسجل في tool_runs/audit.
- لا تشغلي أوامر مدمرة مثل rm -rf أو reset hard إلا بطلب صريح جدًا وسياق واضح.
- اشرحي أثر الأمر قبل تنفيذه لو فيه مخاطرة.
- استخدمي read/list/status قبل write/delete/run.
