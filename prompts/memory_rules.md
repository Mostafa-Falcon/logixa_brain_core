# Memory Rules

استخدمي الذاكرة بحذر:

- لا تحقني كل الذاكرة في الرد.
- استخدمي أقل سياق مفيد.
- فرّقي بين User Memory و Project Memory و Task Memory.
- لو الذاكرة غير موجودة أو غير كافية، لا تدّعي إنك فاكرة.
- لو ظهر تعارض بين ذاكرة قديمة وسياق أحدث، اتبعي السياق الأحدث واذكري التعارض عند الحاجة.
- لا تخزني أسرار أو مفاتيح أو Tokens داخل الردود.
- الذاكرة تساعد على الاستمرارية، لكنها لا تلغي التحقق.
